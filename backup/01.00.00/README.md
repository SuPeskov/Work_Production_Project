Система с персонализированным доступом, содержащая пооперационное описание
производства, монтажа и обслуживания каркасных модульных домов.

Ниже — только команды.

## Запуск локально

Страницы защищены проверкой прав через `/api/me`, поэтому просто открыть
`index.html` в браузере недостаточно — нужен бэкенд:

```bash
cd server && npm install
KB_JWT_SECRET=<hex> KB_DB_PATH=./kb.sqlite KB_ADMIN_PASS='<пароль>' node init-db.js
KB_JWT_SECRET=<hex> KB_DB_PATH=./kb.sqlite node app.js   # http://127.0.0.1:3000
```

Демо-аккаунты создаются при `KB_DEMO=1` (`builder/build456`, `guest1/guest123`).
Прежние логины `admin/admin123` и подобные удалены — пользователи хранятся в SQLite.

## 🔍 Поисковая система

Проект использует Lunr.js для полнотекстового поиска по базе знаний.

### Генерация поискового индекса

После добавления новых операций необходимо обновить поисковый индекс:

```bash
npm install          # один раз: lunr, lunr-languages
npm run build-index
```

Создается файл с поисковыми индексами в public/js/search-index.json на основе разделов и операций в kb.js
Поиск пропускает файлы со статусом черновика 'draft'

### Проверка целостности базы

```bash
npm run audit
```

Сверяет реестр `kb.js`, страницы операций, списки разделов и поисковый индекс:
находит операции без страниц, расхождения `data-op-id`/`data-op-version`,
битые ссылки на фото и PDF, устаревший индекс.

### Обновление версии операции

При редактировании описании операции необходимо изменить data-op-version="i". Установить значение счетчика на i+1. Кнопка "Ознакомился" сбросится.
