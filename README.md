# 🏗️ База знаний — Каркасный модульный дом

Система с персонализированным доступом, содержащая пооперационное описание
производства, монтажа и обслуживания каркасных модульных домов.

## Запуск локально

Откройте `index.html` в браузере или используйте Live Server в VS Code.

## Стек

- HTML5 / CSS3 / Vanilla JS
- Без фреймворков (редактирование в VS Code)

## 🔍 Поисковая система

Проект использует Lunr.js для полнотекстового поиска по базе знаний.
