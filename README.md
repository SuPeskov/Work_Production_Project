## 🔍 Поисковая система

Проект использует Lunr.js для полнотекстового поиска по базе знаний.

### Генерация поискового индекса

После добавления новых операций необходимо обновить поисковый индекс:

```bash
node /opt/scout-kb/server/scripts/build-search-index.js

Создается файл с поисковыми индексами в public/js/search-index.json на основе разделов и операций в kb.js
Поиск пропускает файлы со статусом черновика 'draft'

### Обновление версии операции

При редактировании описании операции необходимо изменить data-op-version="i". Установить значение счетчика на i+1. Кнопка "Ознакомился" сбросится.
